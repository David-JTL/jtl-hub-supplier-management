# GitHub Personal Access Token

Der Token für Claude.ai Git Push wird NICHT im Repo gespeichert.

## Wo ist der Token?

Der Token ist im Claude.ai Projekt unter den Projektdateien hinterlegt:
→ Datei: `GITHUB-ANLEITUNG.md`

## Wie benutze ich den Token?

Im Claude.ai Chat einfach schreiben:

```
Push die Änderungen auf den develop Branch.
Token: <TOKEN hier einfügen>
```

## Token erneuern

1. https://github.com/settings/tokens
2. Neuen Token mit `repo` Scope erstellen (7 Tage Laufzeit)
3. In der Projektdatei `GITHUB-ANLEITUNG.md` aktualisieren
4. Claude im Chat den neuen Token mitgeben
